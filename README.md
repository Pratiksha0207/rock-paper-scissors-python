# Rock-Paper-Scissors Game 🎮

A simple yet engaging command-line implementation of the classic **Rock, Paper, Scissors** game built using **Python**.

## 🚀 Features
- **User vs Computer:** Play against a randomized AI opponent.
- **Input Validation:** Handles invalid numbers and text inputs gracefully to prevent crashes.
- **Emoji Support:** Uses native Unicode emojis for a visually clean console interface.

## 🛠️ Tech Stack
- **Language:** Python 3.x
- **Modules used:** `random` (built-in library for AI choices)

## 💻 How to Run
1. Clone this repository or download the source code.
2. Open your terminal or VS Code.
3. Run the following command:
   ```bash
   python Game.py
   ```
